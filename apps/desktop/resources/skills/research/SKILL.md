---
name: research
description: Investigate a question against primary sources and capture cited findings for Foundry work.
---

Delegate reading legwork to a background agent while the main run continues.

The research run must:

1. Investigate primary sources: official documentation, source code, standards and first-party APIs.
2. Trace every important claim back to the source that owns it.
3. Write findings to one Markdown artifact in the project's documented research location, citing each claim.
4. Return the artifact and its implications to the linked ticket or chat through Foundry's run record.

Research answers a question; it does not silently turn findings into a spec, ticket readiness change or Decision. Put those next steps through the corresponding Foundry proposal and approval flows.
